# LearnPlaywrightBatch2x

This repository contains JavaScript learning examples and practice problems focused on basic JavaScript concepts.

## Structure

- `Chatper01_Basics/`
  - `02_verifySetup.js` — basic setup verification code.
  - `Basics.js` — introductory JavaScript examples.
  - `hotcode.js` — quick test or hot-reload sample code.

- `Chatper02_Javascript_concepts/`
  - `03_basics` — basic JavaScript concept sample (no file extension).
  - `04_variabl creation rule.js` — variable naming rules and conventions.

- `Chatper03_Identifier_Literals/`
  - `comments.js` — examples of JavaScript comments.
  - `Identifier_Part 2.js` — identifier naming and usage.
  - `Rule_identifier.js` — identifier rules and examples.
  - `Rules_identifier part 3.js` — continued identifier rule examples.

- `Chapter04_LET_VAR_CONST/`
  - `hoisting.js` — hoisting behavior in JavaScript.
  - `hoisting_function.js` — hoisting with function declarations.
  - `let_example.js` — examples using `let`.
  - `var_example.js` — examples using `var`.

- `Chapter05_Literal/`
  - empty folder placeholder for literal-related examples.

- `Chatper05_Operator/`
  - `string_con.js` — operator and string-related examples.

- `Chatper06_If_Else_Loop`
  - problem statement file for HTTP status code classification and if-else practice.

## How to run

Use Node.js to execute JavaScript files. If a file name contains spaces, wrap it in quotes.

Example:

```powershell
node "Chatper05_Operator/string_con.js"
node "if_else Leap Year.js"
```
