# LearnPlaywrightBatch2x

This repository contains JavaScript examples and learning exercises organized by chapter.

## Structure

- `Chatper01_Basics/`
  - `02_verifySetup.js` — basic setup verification code.
  - `Basics.js` — introductory JavaScript examples.
  - `hotcode.js` — example code for hot reload or quick testing.

- `Chatper02_Javascript_concepts/`
  - `03_basics` — basic JavaScript concept sample (file without extension).
  - `04_variabl creation rule.js` — demonstrates variable naming rules and conventions.

- `Chatper03_Identifier_Literals/`
  - `comments.js` — examples of JavaScript comments.
  - `Identifier_Part 2.js` — identifier rules and usage.
  - `Rule_identifier.js` — additional identifier rule examples.
  - `Rules_identifier part 3.js` — continued identifier rule examples.

- `Chapter04_LET_VAR_CONST/`
  - `hoisting.js` — example showing hoisting behavior in JavaScript.
  - `hoisting_function.js` — hoisting with function declarations and calls.
  - `let_example.js` — examples using `let`.
  - `var_example.js` — examples using `var`.

## How to run

Use Node.js to execute the JavaScript files:

```bash
node <filename>.js
```

Example:

```bash
node Chapter04_LET_VAR_CONST/hoisting.js
```
